# My Portfolio

A personal portfolio website built with plain HTML and CSS — no frameworks, no JavaScript.

## About

This is my personal portfolio, showcasing who I am, my skills, and the projects I've built. It includes:

- **Home** — introduction and a short bio
- **Skills** — core languages I work with: Java, JavaScript, CSS, and HTML
- **Projects** — a showcase of projects I've built, each linking directly to its GitHub repository
- **Contact** — ways to reach me, including email and social links

## Tech Stack

- **HTML** — page structure and content
- **CSS** — all styling, layout, and responsiveness (including a pure-CSS hamburger menu for mobile, built without any JavaScript)

No external libraries, frameworks, or build tools are used in this project.

## Responsive Design

The site is responsive, with a dedicated layout below 550px that includes a collapsible hamburger navigation menu (implemented using the checkbox/label technique, entirely in CSS).
